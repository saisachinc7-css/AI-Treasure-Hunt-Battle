📚 Theoretical Search Space Complexity

Breadth-First Search (BFS)

Time Complexity: O(V + E)

Space Complexity: O(V)

Expands nodes layer-by-layer. Guarantees the shortest path in unweighted grids but requires storing all nodes in memory, resulting in high memory usage.

Depth-First Search (DFS)

Time Complexity: O(V + E)

Space Complexity: O(V)

Dives deeply along a branch. Highly memory-efficient for deep graphs, but non-optimal. Can return inefficient, winding paths.

Greedy Best-First

Worst Case Time: O(b^d)

Worst Case Space: O(b^d)

Prioritizes nodes based solely on the heuristic Manhattan distance to target. Extremely fast under sparse obstacles, but easily trapped.

A* Search

Worst Case Time: O(b^d)

Worst Case Space: O(b^d)

Combines path cost and heuristic distance evaluation: f(n) = g(n) + h(n). Guarantees optimality and completeness.
